# 3D 手办二次元舞蹈视频技术方案与演进路线 (Figure Video Roadmap)

本文档规划了在 `ContentFlow` 中实现高质量二次元 3D 手办动态舞蹈视频（如 B站“小咩先生”风格）的三种工程化生产路径、工具库集成架构及 API 清单。

## 二、三条路径详解与对比

| 维度 | 路径 1：3D 渲染 + AI 优化流 | 路径 2：2D 关键帧 + 插帧平滑流 | 路径 3：单图 + 视频大模型 API 流 |
| :--- | :--- | :--- | :--- |
| **核心原理** | 3D 骨骼物理驱动 + AI 质感重绘 | 多张姿态图片 + AI 大位移补间 | 单张图片 + 视频生成模型 (I2V) |
| **动作连贯性** | ★★★★★（物理骨骼，零抽搐/零多指） | ★★★☆☆（适合中等幅度动作） | ★★★★☆（大模型动作流畅自然） |
| **视觉手办质感** | ★★★★★（可控光影与材质高光） | ★★★★☆（继承生图模型高画质） | ★★★★☆（受视频模型分辨率限制） |
| **外部 API 依赖** | 低（主要是生图/重绘） | 低（仅需生图 API，插帧本地完成） | **高（必须依赖视频生成大模型 API）** |
| **实现难度与门槛** | 较高（需 3D 资产、Blender 脚本） | 中等（需关键帧一致性提示词） | 最低（一条 API 请求即可出片） |
| **适用阶段** | **最终成熟期终极方案** | **过渡期/离线生成方案** | **当前最快验证可行性的方案** |

## 三、依赖项目与 Submodule 管理

当前项目 `vendor/` 体系规划：

1. **`vendor/MoneyPrinterTurbo`** (Submodule)
   - 作用：成片压制底座，提供字幕排版、音画卡点对齐、商用免版权 BGM 混音。
2. **`vendor/blender_mmd_tools`** (Submodule - 已引入)
   - 作用：路径 1 核心，用于在 Blender 内部解析导入 MMD PMX 角色模型（如能代、2B）与 VMD 舞蹈动作数据。
3. **`vendor/bin/rife/`** (本地 Vulkan 高性能二进制 - 已部署)
   - 作用：跨三条路径的 60FPS 补帧引擎，极速无显存负担。
4. **`vendor/bin/realesrgan/`** (本地 Vulkan 高性能二进制 - 已部署)
   - 作用：跨三条路径的 1080P/4K 超分辨率与抗锯齿去噪引擎。
5. **`core/enhancer.py`** (已完成)
   - 统一暴露 `MediaEnhancer`，供 Python 直接调用 RIFE 和 Real-ESRGAN。

## 四、所需 API 清单与申请指引

根据后续开发的推进，您需要向我提供以下 API Key（需要哪项时填入对应配置即可）：

### 1. 图像生成 API（路径 1、2、3 均需要）
- **推荐**：**火山方舟 Doubao-Seedream-5.0-Pro**
  - **环境变量**：`ARK_API_KEY`
  - **作用**：生成高质感二次元手办人物图（PVC 质感、发丝雕刻、特定角色特征如能代、2B）。
  - **状态**：项目已具备官方 SDK 封装（`.agents/skills/byted-ark-seedream-skill`）。

### 2. 视频生成与动作驱动 API（路径 3 核心必需）
由于目前您手头暂无视频 API，您可以从以下几家中选择申请一项：
- **选项 A：火山方舟 Doubao-Seedance 2.5**
  - **环境变量**：`ARK_API_KEY`（与生图同一账户）。
  - **开通方式**：在火山引擎控制台开通「Seedance 2.5」模型权限。
  - **优势**：当前项目中已内置 `byted-ark-seedance-skill`，只要有 key 立即无缝调用。
- **选项 B：快手可灵 Kling AI API**
  - **环境变量**：`KLING_ACCESS_KEY` & `KLING_SECRET_KEY`
  - **开通方式**：快手开放平台 (klingai.com)。
  - **优势**：目前行业内全身真人舞蹈动作迁移最成熟、肢体控制最稳的商业 API 之一。
- **选项 C：MiniMax (海螺) 视频 API**
  - **环境变量**：`MINIMAX_API_KEY`
  - **优势**：运镜物理质感自然。

### 3. 语音合成 API（若视频包含解说/台词互动）
- **火山引擎 OpenSpeech Seed-TTS 2.0**
  - **环境变量**：`DOUBAO_TTS_API_KEY` 或 `ARK_API_KEY`
  - **状态**：已完整集成在 `core/seed_tts.py`。
