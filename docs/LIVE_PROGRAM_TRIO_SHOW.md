## 一、「18:30 投新片 + 19:00–20:00 直播接力」导流闭环

把主站短视频和直播间做成相互供血的“晚间黄金两小时”：

```text
18:30 新片定时公开（1 分钟以上剧场版短片）
   │  └─ 视频置顶评论礼貌预告：今晚 19:00 三人合租直播间现场复盘 + 弹幕公投下期剧本（严禁群发艾特用户）
   ▼
19:00–20:00 铁三角 60 分钟主题直播接力
   │  ├─ 开场承接刚看完新片的观众，聊 017–020 幕后彩蛋与 15/1000 粉进度
   │  ├─ 中段开放右侧实时弹幕投票条（扣1 / 扣2 / 扣3），观众当场决定下期谁当主控、拍什么脑洞
   │  └─ 实时记录礼物致谢、弹幕暴涨、毒舌名场面与涨粉喜报时间戳
   ▼
20:00 准点自动关播 → 20:05 空载内存串行出切片
      └─ 直接读取自动导出的 live_highlights_ffmpeg_clip_plan.json，剪出 60–90 秒高光名场面，
         次日精修或做成番外短片反哺主站，把高光观众再次导入下一晚的 19:00 直播间。
```

### 导流执行要点

1. **视频置顶引流（礼貌克制）**：18:30 新片公开后，在置顶评论中自然提示「今晚 19:00–20:00 大肥鱼、Gemini娘、弱音大姐头在主页直播间合体复盘，扣 1 / 扣 2 / 扣 3 现场公投下期剧本！」，不发刷屏广告，不群发艾特任何用户名。
2. **直播共创锁定回头客**：观众在直播间公投胜出的选项、以及高赞安全脑洞，直接作为后续新片选题或开场彩蛋，让参与投票的观众第二天愿意回来看“兑现结果”。
3. **切片反哺主站**：直播过程中高光追踪器会自动标注高能时刻并输出 `ffmpeg` 切片命令，下播停流后即可在空载状态下轻松截出 60–90 秒爆笑片段。

## 四、开箱即用启动命令

> 每次启动前请先执行 `free -m`，确认可用内存（`available`）不低于 `5000 MiB`，且后台没有任何视频渲染或质检进程。

### 4.1 15 秒本地离线预览（零推流、零账号风险、快速验收舞台画面）

```bash
free -m

./.venv/bin/python scripts/launch_headless_live.py \
  --mode dry-stream \
  --cast trio \
  --duration-sec 15 \
  --no-edge-tts \
  --poll-topic "下期主控弹幕公投" \
  --poll-options "大肥鱼,Gemini娘,弱音大姐头" \
  --follower-count 15 \
  --follower-goal 1000 \
  --output-mp4 /tmp/trio_live_preview.mp4 \
  --frame-dump-path /tmp/trio_live_stage_preview.png
```

说明：
- 去掉 `--no-edge-tts` 后，在联网环境下会自动启用三位角色专属免费神经语音（断网时自动平滑回退到高区分度三声部离线旋律，绝不中断）。
- 跑完后直接打开 `/tmp/trio_live_stage_preview.png` 检查三角色站位、投票进度条、弹幕墙、字幕与右上角 `GB 45438-2025` 标识。

### 4.2 正式 60 分钟三人铁三角开播（19:00–20:00 接力场）

```bash
free -m

./.venv/bin/python scripts/launch_headless_live.py \
  --mode go-live \
  --cast trio \
  --duration-sec 3600 \
  --area-id 1062 \
  --title "【铁三角AI合租直播】大肥鱼×Gemini娘×弱音现场弹幕公投！15粉冲1000粉" \
  --poll-topic "下期主控弹幕公投" \
  --poll-options "大肥鱼,Gemini娘,弱音大姐头" \
  --follower-count 15 \
  --follower-goal 1000 \
  --record-dir output/live_sessions/trio_show_01
```

说明：
- **分区建议**：科技与 AI 互动场用 `--area-id 1062`；若希望归入虚拟主播日常分区，可改为 `--area-id 371`。
- **双人兼容模式**：若某场只想播双人版，只需将 `--cast trio` 改为 `--cast dual`。
- **首次开播人脸校验**：如平台返回需人脸核验（状态标签 `FACE_AUTH_REQUIRED`），程序会自动生成官方扫码二维码至 `output/live_face_auth_qr.png` 并干净退出，使用 B 站手机端完成官方认证后重跑同一命令即可。
- **自动兜底关播**：满 3600 秒、按 `Ctrl+C` 或遇到网络中断时，程序始终在收尾阶段自动调用停播接口，并在 `--record-dir` 中保存 `live_highlights.jsonl` 与 `live_highlights_ffmpeg_clip_plan.json`。

### 4.3 下播后查看并执行高光切片清单

停播退出后，在终端查看自动生成的 60–90 秒高光切片计划：

```bash
cat output/live_sessions/trio_show_01/live_highlights_ffmpeg_clip_plan.json
```

挑出评分最高、笑点最密集的片段，直接复制清单中的 `ffmpeg_cmd` 在空载内存下串行裁切，即可得到 1080P 60FPS 高清切片素材。

## 五、可选接入真实大模型自由接梗指南（零密钥入库）

不配置任何 API 密钥时，直播引擎会自动使用内置的三人组精选离线喜剧词库稳定开播；如果希望三位主角根据观众千奇百怪的弹幕自由即兴接梗，可以在当前终端临时注入 OpenAI 兼容接口密钥（例如 DeepSeek API）：

```bash
# 仅在当前终端会话生效，严禁写入代码仓库、文档或 Git 提交记录！
export LIVE_LLM_API_KEY="填入你的本地密钥"
export LIVE_LLM_BASE_URL="https://api.deepseek.com/v1"
export LIVE_LLM_MODEL="deepseek-chat"

# 随后正常启动直播命令即可自动切换为实时大模型接梗
./.venv/bin/python scripts/launch_headless_live.py \
  --mode go-live \
  --cast trio \
  --duration-sec 3600 \
  --record-dir output/live_sessions/trio_llm_show
```

安全兜底保障：
1. **绝不提交密钥**：密钥仅从环境变量读取，日志、异常和状态回执中永不打印密钥内容。
2. **断网/超时秒级回退**：若大模型接口超时或返回错误，系统会自动回退到内置离线喜剧词库，直播画面与声音不断档。
3. **输出合规二次审查**：大模型生成的每一句台词都会先经过合规护栏过滤，拦截任何隐私信息、敏感词或艾特用户名，命中即替换为对应角色的自然转场台词。

## 六、24 GiB 内存错峰铁律与开播前核对清单

本机内存上限为 24 GiB（显存 8 GiB），为防止直播掉帧或系统内存耗尽，必须严格执行以下错峰规约：

1. **绝不边播边本地渲染 60FPS**：直播推流（19:00–20:00）期间，严禁同时启动 60 帧光流补帧、批量抠图、画质模型质检、本地语音推理、全量自动化测试或第二路视频转码。
2. **分时错峰日程**：
   - **白天 / 18:00 前**：串行完成当晚 18:30 新片的生成、补帧、封面合成、质量门禁与定时投稿；
   - **18:50–19:00**：执行 `free -m` 确认可用内存 `>= 5000 MiB`，清理多余进程；
   - **19:00–20:00**：单进程专注运行三人无头直播；
   - **20:05 以后**：确认推流已完全关闭，再串行执行高光切片裁切或次日新片生产。
3. **开播前 5 项必查**：
   - [ ] `free -m` 显示可用内存不低于 `5000 MiB`；
   - [ ] 右上角 `本直播间由 AI 实时驱动互动 · GB 45438-2025` 标识完整清晰、无遮挡；
   - [ ] 标题、投票议题、选项与置顶预告中不含任何个人隐私信息、敏感词或艾特用户名；
   - [ ] 三位主角画面无拉伸重叠，右侧实时投票进度条与弹幕卡片层次清晰；
   - [ ] 仅使用本工作室已授权的开源与同人角色素材及合规背景伴奏。
