## 一、 为什么以往生图会失败？

| 常见缺陷 | 产生根因 | 针对性解法 |
| :--- | :--- | :--- |
| **塑料黏土假发/粗糙大发块** | 提示词中过度堆叠 `figure`, `plastic`, `toy`，模型将头发误解为粗制泥塑粘土 | 强化发丝流光提示词：`奢华瀑布银发，顶级真发丝渲染，如上等丝绸般柔顺丝滑，发丝根根分明细如蚕丝，几缕碎发优雅拂过锁骨，绝无塑料感`；负向加入 `塑料头发, 泥塑感, 粗糙大发块` |
| **身形直筒保守呆板** | 缺少体态比例约束，模型倾向于泛化保守常态 | 引入高吸引力二次元手办美学：`成熟丰满极致沙漏型身材，傲人挺拔胸围，纤细收束柔软蜂腰，优美腰臀曲线，极品微透肉黑色高光丝袜（sheer black pantyhose with skin translucency and lustrous sheen）` |
| **生硬左右分屏/拼图** | 在单次生图中强行要求“左边人右边板”，模型 latent 分裂 | **底图与人物完全分离生成**：先生成 2560x1440 纯净科技教室，再独立生成人物并抠图合成，比例与位置 100% 确定 |
| **多张图人物脸型服装变形** | 仅靠文生图每次随机扩散 | **图生图特征锚定**：以第一张全身立绘为基准进行 Base64 编码作为参考图，仅改变【动作神态】字段 |
