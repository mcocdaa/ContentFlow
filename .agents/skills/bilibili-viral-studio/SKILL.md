# Bilibili Viral Studio Skill (B站爆款工程与100分制质量门禁规范)

本技能将 ContentFlow 在 B站（Bilibili）二次元宅舞、3D 手办硬核科技科普与 AI 整活实录赛道的生产经验，沉淀为 **15 条爆款铁律**、**100 分制客观质量门禁 (Quality Rubric)**、**16:9 封面大字排版规范** 与 **借物表/AIGC 法律合规红线**。

---

## 一、 B站视频「有人看 vs 没人看」的 15 条生死铁律

### A. 封面与标题（决定点击率 CTR 的前 0.5 秒）
1. **铁律 1（严禁 9:16 竖图直充封面）**：无论成片是 9:16 竖屏宅舞还是 16:9 横屏科普，**投稿封面必须 100% 是 `1920x1080` (16:9) 横图**。若直接上传 9:16 竖图作为封面，B站双列推荐流与 PC 端将其强制裁切为 16:9 / 4:3 时会直接砍掉人物头部与下半身。
2. **铁律 2（4:3 中心安全框原则）**：B站移动端与动态流常以 `4:3` 比例裁切预览，因此封面所有文字、胶囊角标与核心人物视觉重心必须严格落在 **`x: 240..1680`（中心 `1440x1080` 安全区）** 内，左右各留 `240px` 缓冲翼。
3. **铁律 3（3 行超大描边撞色字）**：封面不可只有底图无文字，也不可堆砌密密麻麻的小字。采用 `NotoSansCJK-Bold.ttc` 渲染 **不超过 3 行超大主标题**（首行亮金 `#FFD700`、次行纯白 `#FFFFFF`、末行赛博青 `#00F0FF`），配合 **8px 纯黑描边 + 高斯投影**，确保在手机缩略图下 0.3 秒可读。
4. **铁律 4（叙事反差痛点标题）**：拒绝干瘪说明书式标题（如《Transformer原理解析》），必须采用 **「悬念/身份反差 + 具象角色/视觉奇观 + 情绪标点（？！）」**，例如：`当我把B站账号和可灵会员交给AI：它自己连夜肝出了这条蓝色大肥鱼热舞？！`。
5. **铁律 5（精准分区 TID 与长尾标签矩阵）**：虚拟形象热舞投递 `宅舞 (tid=20)`，3D 手办讲大模型投递 `计算机技术 (tid=231)` 或 `校园学习 (tid=208)`，配置 10-12 个高热度话题标签（如 `#B站AI创造公开赛`、`#DeepSeek`、`#蓝色大肥鱼`）。

### B. 黄金前 3 秒与视听动态密度（决定完播率与留存）
6. **铁律 6（前 3 秒零废话强钩子）**：严禁前 3 秒黑屏、静态 Logo 淡入或“大家好今天我们来聊…”。第 0.0 秒必须直接进入最高能动态画面（副歌卡点起舞 / 报错暴雷痛点直击）。
7. **铁律 7（消灭 >4 秒静态PPT死帧）**：技术科普严禁一张静态图干讲 20 秒。必须通过多动作立绘切换、全息白板分步高亮或 `zoompan` 慢推运镜保持视觉熵流动。
8. **铁律 8（消灭上下左右死黑边）**：竖屏或非标素材严禁直接加纯黑边（Letterbox/Pillarbox），必须使用深海/赛博高斯模糊流光背景满屏填充。
9. **铁律 9（伪影零容忍与全息 HUD 遮罩）**：AI 底图中的乱码伪影（如白板右下角的 `(f:ILnix)`）必须通过 `CoverDesigner` 或图层合成器使用精准全息公式卡片覆盖修复。

### C. 音画工程与硬核流参数（决定推荐池权重与质感）
10. **铁律 10（分辨率与 60FPS 满帧丝滑度）**：成片短边分辨率必须 `>= 1080`（横屏 `1920x1080` 或竖屏 `1080x1920`），像素格式 `yuv420p` (`bt709`)；宅舞与高动态视频必须达到 **60fps**（码率 `>= 4 Mbps`），科普视频 `>= 30fps`（码率 `>= 1.5 Mbps`）。
11. **铁律 11（响度标准化与防爆音）**：音频平均响度控制在 `-18 dBFS ~ -11 dBFS`（对齐 EBU R128 `-14 LUFS`），峰值严格控制在 `<= -0.1 dBFS`（推荐 `-1.0 dBTP`），严禁无音轨或削波爆音。
12. **铁律 12（音画毫秒级对齐）**：视频流与音频流时长偏差必须 `<= 0.35s`，杜绝尾部黑屏无声或台词被腰斩。

### D. 社区互动与合规护城河（决定硬币率、收藏率与账号安全）
13. **铁律 13（时间轴章节导航与置顶评论投票）**：技术科普必须在简介提供精确到秒的 `00:00` 章节导航（直接拉升收藏率），并在置顶评论发起「二选一选题投票 + 赛博股东养成计划」（拉升评论率）。
14. **铁律 14（二创借物表 Credits 礼仪）**：凡涉及开源虚拟形象（如 DeepSeek 蓝色大肥鱼）、游戏/动漫角色（如能代、2B、弱音）、MMD 动作数据（如 `ureshiiiiii`）与 BGM，必须在简介显著位置附上完整 **【借物表 (Credits)】**。
15. **铁律 15（商用字库、声优红线与 GB 45438-2025 AIGC 标识）**：
    - **字库合规**：彻底禁用微软雅黑（`MicrosoftYaHei`）、华文黑体（`STHeiti`）、中易黑体（`SimHei`）等闭源商业字体；100% 采用思源黑体（`NotoSansCJK-Bold.ttc` / `SIL Open Font License 1.1`）与文泉驿正黑（`wqy-zenhei.ttc`）。
    - **声音红线**：依据《民法典》第 1023 条，**严禁未经授权克隆真人或动漫声优（如石川由依等）原声**，必须 100% 使用火山引擎 Seed-TTS 2.0 或 Edge-TTS 官方商用授权合成音色。
    - **AIGC 标识**：依据 **GB 45438-2025《人工智能生成合成内容标识办法》**，必须在简介与元数据中显式声明 AI 生成合成属性。

## 二、 100 分制客观质量评判门禁 (Quality Rubric)

`core/quality_gate.py` 中的 `VideoQualityGate` 对项目执行全自动客观打分（满分 100 分，`>= 80` 分且无 Blocker 方可准出）：

| 维度 | 满分 | 核心客观检测指标（`ffprobe` / `ffmpeg` / `Pillow` / 文本） |
| :--- | :---: | :--- |
| **1. 技术流参数 (`technical`)** | **20 分** | 短边 `>=1080` (6分) + `h264/yuv420p` (2分) + 帧率 `60fps/30fps` (6分) + 视频码率与 `bt709` 色彩空间 (6分) |
| **2. 音频工程与响度 (`audio`)** | **20 分** | `AAC >=44.1kHz` & 码率 (6分) + `volumedetect` 平均响度 `-24~-9dB` & 峰值不爆音 (8分) + 音画时长同步差 `<=0.35s` (6分) |
| **3. 视觉动态与前3秒钩子 (`visual_dynamics`)** | **20 分** | 前 3 秒帧间运动差分与视觉对比度 (8分) + 全片多点采样动态密度防死帧 (7分) + 上下边缘无死黑边检测 (5分) |
| **4. 封面CTR大字与比例 (`cover_ctr`)** | **20 分** | `1920x1080` 标准 `16:9` 横版比例 (6分) + `4:3` 中心安全框 (`x: 240..1680`) 描边边缘密度与 `*_4x3.jpg` 伴生图 (7分) + 明暗对比度动态范围 (7分) |
| **5. 元数据与借物表合规 (`compliance`)** | **20 分** | 爆款钩子标题与情绪标点 (5分) + 分区 TID 与 `>=5` 标签 (4分) + 完整借物表原作者署名 (6分) + GB 45438-2025 声明与字库/声音红线 (5分) |

### 🚨 一票否决项 (Blockers)
一旦触发以下任一 Blocker，门禁直接判定为 `BLOCKED (Grade F)`，禁止直接发布：
- 成片 MP4 缺失或无有效视频流 (`video_missing`)
- 封面图缺失或比例非 `16:9` 横图（例如误用 `9:16` 竖图当封面）(`cover_not_16x9`)
- 视频无音轨或全程死寂无声 (`audio_missing_or_silent`)
- 音画时长严重脱节 (`abs(v_dur - a_dur) > 1.5s`)
- 触碰未授权商业字体或声优原声克隆红线 (`compliance_redline_violation`)

## 三、 CLI 工具与代码调用指南

### 1. 生成 B站 16:9 高 CTR 爆款封面（`design-cover`）

自动将项目的 `9:16` 竖图（如 `007` 的大肥鱼立绘）或 `16:9` 横图（如 `005` 的能代教学场景，自动修复白板伪影）渲染为 `1920x1080` 横版大字封面与 `1440x1080` (4:3) 安全裁切预览图：

```bash
# 使用项目内置爆款预设一键生成 007 与 005 封面
./.venv/bin/python cli.py design-cover --project 007
./.venv/bin/python cli.py design-cover --project 005

# 自定义三行大字标题、顶部胶囊角标与底部亮点标签
./.venv/bin/python cli.py design-cover \
  --project 007 \
  --hook-line1 "把B站账号交给AI" \
  --hook-line2 "连夜肝出大肥鱼" \
  --hook-line3 "60帧纯享热舞！" \
  --badge "AI接管账号实录" \
  --tags "2K深海重绘,60FPS满帧"
```

### 2. 运行 100 分制客观质量门禁（`quality-check`）

```bash
# 终端可视化报告模式
./.venv/bin/python cli.py quality-check --project 007
./.venv/bin/python cli.py quality-check --project 005

# 输出结构化 JSON 报告供自动化流水线消费
./.venv/bin/python cli.py quality-check --project 007 --json
```

### 3. 自动生成项目借物表与 GB 45438-2025 合规声明

```python
from core.asset_library import AssetLibrary

lib = AssetLibrary()
credits_markdown = lib.generate_project_credits("007_deepseek_dafeiyu_phone_number")
print(credits_markdown)
```
