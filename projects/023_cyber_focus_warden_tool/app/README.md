# 赛博防摸鱼毒舌监工 (Cyber Focus Warden)

一个**零三方依赖、纯 Python 标准库 + 现代暗黑玻璃态前端**的本地防摸鱼专注工具。  
不联网也能 100% 开箱即用，**零摄像头、零麦克风、零隐私数据上传**。

## 一行命令本地启动

```bash
python3 app.py
```

启动后在浏览器打开 `http://127.0.0.1:8780/` 即可使用！

自定义端口或随机可用端口：

```bash
python3 app.py --port 8780
python3 app.py --port 0
```

## 核心功能

1. **番茄专注引擎**：支持 `25m 标准番茄` / `15m 快速冲刺` / `10s 演示模式`，内置 Web Audio 合成提示音。
2. **真实浏览器切屏探测**：基于原生 `document.visibilitychange` + `window.blur` 实时统计失焦秒数与切屏次数。
3. **3 级升级惩罚状态机**：
   - **Lv.1（失焦 3 秒）**：柔和警告提醒，劝你立刻回归任务。
   - **Lv.2（第 2 次或超 8 秒）**：顶部滚动毒舌弹幕拷问 + 赛博功德扣分。
   - **Lv.3（连续累犯）**：全屏红蓝警报「摸鱼通缉令」+ 强制复盘认错口令 + 一键生成《今日摸鱼罪证小票》。
4. **双引擎毒舌文案**：
   - **默认离线开箱即用**：内置 3 档 48 条接地气幽默毒舌台词，无需任何 API Key。
   - **可选接大模型**：若环境变量配置了 `OPENAI_API_KEY`（及可选 `OPENAI_BASE_URL`、`OPENAI_MODEL`），自动优先调用模型实时定制吐槽，异常时无缝回退本地词库。

## API 接口

- `GET /`：返回暗黑玻璃态专注界面 (`index.html`)
- `GET /api/health`：返回运行模式与本地毒舌库状态
- `POST /api/roast`：根据警报等级（1/2/3）、切屏次数与摸鱼秒数返回毒舌台词与弹幕池
- `POST /api/receipt`：生成结构化与纯文本《今日摸鱼罪证小票》
