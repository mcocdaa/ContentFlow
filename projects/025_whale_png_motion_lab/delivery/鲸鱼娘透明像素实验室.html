把自己的透明图命名为 whale.png，和下面的 HTML 放在同一目录。双击 HTML 就能看见呼吸动画。

<meta charset="utf-8">
<style>
  body { background: #92cadd; }
  img {
    height: 220px; width: auto;
    transform-origin: 50% 100%;
    animation: up 2s ease-in-out infinite alternate;
  }
  @keyframes up {
    to { transform: translateY(-8px) rotate(3deg); }
  }
</style>
<img src="whale.png" alt="鲸鱼娘">
