大家好，最近几个月业余时间折腾了一个新项目：**AI 管理 AI 工作深度调研与 TermFlow 控制舱**。

### 背景痛点
平时在开发和业务协作时，深感现有的一些方案实在太重或者太不顺手了：
- 执行黑盒与断网雪崩：传统 HTTP API 抖动或超时导致底层的长耗时编译/微调子进程被操作系统 SIGHUP 强杀，前功尽弃
- 失控爆炸半径与安全失守：工人 AI 遇到报错产生幻觉，暴力执行 rm -rf / 或泄露包含数据库凭据的生产密钥
- 异构孤岛与内网穿透壁垒：生产服务器和 GPU 工作站深居内网 NAT，开放公网 SSH 22 端口面临毁灭级渗透风险
- 人机在环（HITL）严重脱节：多智能体陷入死锁僵局时，控制台只有满屏乱滚的 JSON 日志，人类工程师无法无缝切入交互式 TTY 现场排障


很多时候我就想要一个轻量、稳定、可预期、能开箱即用的工具，而不是为了喝口水先搭一套水厂。

### 做了什么
项目定位：**从认知编排到物理控制舱：多智能体分层管辖的技术死穴与 TermFlow 架构破局**。
核心实现：
- tmux 原生虚拟化与长任务状态机：任务与客户端网络彻底解耦，即便断网或主管 AI 重启，底层长期任务雷打不动，随时秒级恢复
- 主动反向安全穿透连接：计算执行节点（Computer A）主动向控制面建立加密 WSS 长连接，零公网端口暴露，轻松穿透多重企业 NAT
- 内建 Agent Broker 与标准 MCP 协议：对外暴露标准 Model Context Protocol 接口，固化工具白名单，彻底封禁未受控的破坏性底层工具
- Level 4 审批护栏与结构化 Unified Diff 审查：只读操作秒级放行，高危写入与破坏性指令强制拦截挂起，生成类似 GitHub PR 的 Diff 供人类一票否决
- 终极人机共管：移动端专属 18 键触觉按键坞，工程师在通勤或深夜随时用手机秒级接管报错会话现场


技术选型上尽量克制：`Python 3.12+, FastAPI & asyncio, tmux & POSIX System Calls, Model Context Protocol (MCP), TypeScript & Vue 3, xterm.js & Tauri 2, Docker Compose`，尽量不引入不必要的重型外部常驻服务，单机或单镜像即可轻松搞定。

### 核心亮点
1. **tmux 原生虚拟化保活**：长任务永不掉线，彻底告别断网暴毙。深度接管操作系统 tmux 守护进程，使长耗时编译、依赖下载与模型训练拥有独立生命周期，连接断开后台安然运行，重连秒级恢复现场 ANSI 字符流。
2. **主动反向穿透长连接**：零公网端口暴露，内网算力即插即用。执行节点主动发起 WSS 出网连接，无需公网 IP 与路由器端口映射，彻底消除企业合规阻碍与安全渗透隐患。
3. **原生 MCP Agent Broker**：紧密拥抱行业开放标准，安全沙箱隔离。作为中立安全中介暴露标准 Model Context Protocol 服务，支持 OpenCode、Claude Code、DeepSeek 等大模型一键接入，强制工具白名单隔离。
